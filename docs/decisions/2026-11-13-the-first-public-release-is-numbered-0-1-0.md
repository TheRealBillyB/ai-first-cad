# The first public release is numbered 0.1.0

This replaces the 2026-11-08 decision to number the next release 0.9.0. Version 0.1.0 is the first public early release: it works for real designs, but expect rough edges, missing features, and performance gaps. Feedback is welcome. Version 1.0 still follows once the assembly flow and other gaps are in better shape.
