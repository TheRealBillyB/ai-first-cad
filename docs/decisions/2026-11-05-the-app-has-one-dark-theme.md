# The app has one dark theme

The panels now match the dark 3D view, with amber as the only accent color and a light sheet kept only behind pictures the server draws on one. The grid and origin axes are drawn first with depth testing off, so every part covers them and a click hits what it hit before. The grid sits on z = 0, and the view shows its spacing, because a grid with no stated size can be misread as a scale.
