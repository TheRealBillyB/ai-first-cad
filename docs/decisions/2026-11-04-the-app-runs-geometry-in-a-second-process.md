# The app runs geometry in a second process

OpenCascade holds Python's lock through a long operation, so threads could not keep the page answering. On one measured boolean, a state read waited 4.8 s in one process and at most 0.03 s with the worker. One worker owns the real workspace, and one request runs at a time, as the workspace lock already required. A worker that dies is replaced from the saved project, so a kernel crash no longer ends the app, but that session's undo history and selection are lost. Stopping a running command is not part of this.
