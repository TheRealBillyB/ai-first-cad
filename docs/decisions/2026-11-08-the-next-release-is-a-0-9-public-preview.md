# The next release is a 0.9.0 public preview for feedback

This replaces the 2026-10-24 decision to make the next release v1.0. Version 0.9.0 lets people try what is in the tree and report what is confusing before 1.0. Model and Assembly now share one workspace and one 3D view, but the assembly flow is new and still rough. Version 1.0 will add editing a part in place inside an assembly and polish that flow, shaped by preview feedback. CAM and manufacturing checks remain planned after 1.0.
