# The next release is a 0.9.0 public preview for feedback

This replaces the 2026-10-24 decision to make the next release v1.0. Version 0.9.0 lets people try what is in the tree and report what is confusing before 1.0. Modeling and assembly are separate workspaces today, and the assembly flow is hard to follow. Version 1.0 will merge them into one workspace and redesign that flow, shaped by preview feedback. CAM and manufacturing checks remain planned after 1.0.
