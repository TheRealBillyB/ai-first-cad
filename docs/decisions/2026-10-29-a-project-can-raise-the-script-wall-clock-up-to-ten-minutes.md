# A project can raise the script wall clock up to ten minutes

The default wall clock for a design script stays 120 seconds. A gear set with a hypoid ring and pinion ran past that. The person can set a longer limit for one project, up to 600 seconds, in the account config. A file in the project cannot raise it, the environment cannot raise it, and a script cannot change it. The sandbox and the other limits stay as they are.
