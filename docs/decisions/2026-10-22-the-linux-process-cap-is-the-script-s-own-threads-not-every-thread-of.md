# The Linux process cap is the script's own threads, not every thread of the user

`RLIMIT_NPROC` is per user, so a 256 cap stalled geometry when a browser was open; a cgroup `pids.max` or the parent counting the script's threads does not, and classic seccomp cannot count `clone` or `fork`.
