# `create_sketch` / `get_sketch`

Solve a sketch. Constraints include parallel, perpendicular, tangent, equal, angle, radius, symmetric, and midpoint. `construction` true on a line, circle, or arc is construction geometry. The report says fully constrained, under-constrained (which entities can still move), or over-constrained (which constraints conflict). The image has the dimensions labeled.
