# `render_animation`

GIF of a motion study, a camera orbit, or an exploded opening. MP4 or WebM when ffmpeg is on PATH. An int color is three bytes from 0 to 255, so (1, 1, 0) stays nearly black. A float color from 0 to 1 is a fraction of full scale, so (1.0, 1.0, 0.0) is yellow. A float above 1 is a byte already on that scale.
