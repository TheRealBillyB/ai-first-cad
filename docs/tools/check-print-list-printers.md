# `check_print` / `list_printers`

Overhang map, a suggested orientation, and printer fit for a part or for an assembly in its current pose. A short bridge is not counted as support. A slicer estimate is included when PrusaSlicer or OrcaSlicer is installed. `layer_height_mm` sets that slicer's layer height. When that slicer warns that the print needs supports, the slice is run again with supports turned on.
